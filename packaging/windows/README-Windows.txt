VideoLoader - тестовая сборка Windows 11 x64

Установщик не подписан сертификатом издателя. Не отключайте антивирус
или SmartScreen. При блокировке сохраните сообщение. Проверяйте источник
и SHA256 из того же задания GitHub Actions. Хеш не заменяет подпись.

Установка приложения для текущего пользователя. Зависимости отдельно
через WinGet, только после ввода YES. Возможны дополнительные запросы прав.
Пакеты: yt-dlp.yt-dlp, yt-dlp.FFmpeg, DenoLand.Deno.
Rust и Cargo конечному пользователю не нужны.

Используйте ярлык: он обновляет PATH для процесса из настроек Windows.
Диагностическая консоль оставлена для тестов. ExecutionPolicy Bypass
действует только в процессе запуска локальных скриптов комплекта,
постоянную политику системы не меняет. Политики организации могут
запретить такой запуск; не пытайтесь их обходить.

Пакетная проверка yt-dlp-ejs в приложении пока только для Arch.
В Windows сообщение «Не проверен» для EJS ожидаемо; это не доказательство
его отсутствия. Проверьте анализ реальной ссылки YouTube.
Установка из окна приложения пока только для Arch; в Windows используйте
ярлык «VideoLoader - зависимости».

Проверьте анализ, качество, озвучку, MP3, VK/Rutube, папку с пробелами
и кириллицей, отмену, паузу и восстановление очереди.
Удаление приложения не удаляет зависимости, видео и настройки.

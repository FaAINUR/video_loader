# VideoLoader 0.9.0

Модульная версия. Хранение настроек и очереди совместимо с 0.8.0.

## Структура

| Файл | Ответственность |
|---|---|
| `src/main.rs` | Запуск окна |
| `src/models.rs` | Типы данных, настройки, формат хранения |
| `src/rules.rs` | Проверка ссылок, прокси, путей, параметров задач |
| `src/progress.rs` | Разбор строк вывода yt-dlp |
| `src/ytdlp.rs` | Аргументы, разбор JSON, запуск процесса |
| `src/jobs.rs` | Состояние задачи, сохранение и восстановление очереди |
| `src/platform.rs` | Linux и Windows: процессы, консоль, открытие папок |
| `src/app.rs` | Состояние приложения и действия |
| `src/app/ui.rs` | Отрисовка интерфейса |

## Команды

    cargo fmt
    cargo check
    cargo test
    cargo clippy --all-targets
    cargo run

## Тесты

Юнит-тесты находятся рядом с кодом в блоках `#[cfg(test)]`.
Они не требуют сети, yt-dlp и FFmpeg.

Не покрыто тестами: окно (egui), реальный запуск yt-dlp и FFmpeg,
отмена процессов, системные диалоги, платформенный код Windows.

## Известные ограничения

- Встраивание обложки в MKV/MP4 работает нестабильно.
- Версия не компилировалась автором PDF/кода в среде создания; проверяйте `cargo check`.
